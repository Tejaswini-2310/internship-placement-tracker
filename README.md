# Skill2Hire - Internship Application Tracker

Skill2Hire is a web-based Internship Application Tracker designed to help students organize, monitor, and manage their internship applications in one place.

## Features

- Add internship applications
- Track company and job role
- Track application date and deadline
- Manage application status
- Search applications
- Filter applications by status
- Edit existing applications
- Delete applications
- Add job links
- Add application notes
- Track application progress
- View upcoming deadlines
- Maintain a personal career profile
- Store application data using browser LocalStorage
- Responsive pastel-themed dashboard UI

## Application Status

Skill2Hire supports the following application stages:

- Saved
- Applied
- Assessment
- Interview
- Selected
- Rejected

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Responsive Web Design
